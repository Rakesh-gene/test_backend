# GAP-006: Native Codex approvals

Implemented 8 November 2026 for the user's current Codex-only scope. This implements
the approval relay; it does not complete all P08 research/planning features or add
Claude/Copilot adapters.

`kode agent start <root> --prompt "..."` creates a durable assignment. Optional
`--model` and `--reasoning` are checked against the native model catalogue, including
the effective default model. `--sandbox workspace-write --tree <id>` requires an
isolated writable task tree. `kode agent get/cancel <id>` inspects or interrupts it.

The rich terminal shows native command/file/permission/question requests, scope,
reason, available choices, expiry, fingerprint, delivery and tool outcome. Enter
arms the selected request; unarmed keys cannot approve. The details view (`d`, then
`j/k`) exposes bounded full native scope. Structured questions validate IDs and
options; secret input is masked and answers are not persisted. Headless clients use
`approval inspect` and `approval decide` with the displayed version/fingerprint.

Decisions are persisted before relay and bound to the transport epoch, native
request/thread/turn/item, operation fingerprint and version. SQLite CAS and
serialized transitions reject stale/conflicting decisions. Identical transport
frames invoke one callback; changed reuse of an ID closes the connection. Only
advertised one-invocation choices are exposed. When Codex offers accept/cancel, the
terminal explicitly labels denial as cancellation of the turn. No session-wide or
execution-rule grant is synthesized.

Filesystem expansion requests, file edits in read-only assignments, and additional
file-change grant roots cannot be approved through this relay. They require a newly
scoped assignment, so an agent cannot use a turn permission request to grant itself
access to Kode's control credential. Supported network permission requests remain
explicit turn-scoped decisions.

Native acknowledgement and command success are separate durable states. Expiry,
cancellation and disconnect never create a grant. Restart supersedes pending
requests, marks uncertain delivery unknown, blocks the old assignment and never
reconstructs callbacks or replays work. Approval/agent trace carriers are retained;
recovery runs under the saved parent context.

The control credential now lives in private `.kode/control/control.token`. Native
assignments must confirm the custom permission profile that denies this directory
before dispatch. A model's refusal is not used as evidence of OS enforcement.
Legacy running versions must be stopped/restarted when upgrading the token path;
the client gives an explicit diagnostic instead of reading an old credential.

Evidence and reproduction:

- `tests/approval-broker.test.ts`: invocation identity, competing/stale decisions,
  acknowledgement versus failed execution, timeout and restart reconciliation.
- `tests/provider-transport.test.ts`: a real local transport with string request
  IDs, duplicate frames and changed-operation rejection.
- `tests/agents.test.ts`: structured answers, file denial, permission profile,
  model/reasoning validation and separate outcomes, using a labelled protocol fixture.
- `node scripts/qualify-native-approvals.mjs`: authenticated Windows Codex plus real
  PTY, actual denial/cancellation, approval, and exit-7 command failure. Result:
  `.artifacts/GAP-006-native.json`, three live scenarios. Controller decisions apply
  only to its disposable marker commands; this script is an explicit acceptance run.
- `node scripts/qualify-native-recovery.mjs`: kills only its disposable runner while
  an actual native request is pending. Restart rejects the old grant, reports the
  agent blocked and leaves the command marker absent. Result:
  `.artifacts/GAP-006-native-recovery.json`.
- `node scripts/qualify-native-boundary.mjs`: native kernel denial of a synthetic
  control-file read and out-of-scope write, plus successful in-scope write, with
  managed configuration included. Result: `.artifacts/GAP-007-native-boundary.json`.

Live inference/kernel qualification above was performed on Windows x64 with Codex
0.164.0. Credential-free protocol tests run in native CI. Other native-provider/OS
combinations remain explicit P08/P13 qualification gates; fixture tests do not
claim live file-edit or user-question inference on those hosts.

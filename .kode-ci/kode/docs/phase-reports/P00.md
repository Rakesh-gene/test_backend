## Corrections found by iteration

- The initially resolved Tree-sitter runtime/grammar pair was incompatible. Switched to the maintained VS Code WASM grammar bundle and proved the parse with the actual runtime.
- Initial SQLite version 13 caused an implicit native compiler build during a fresh installation. Pinned 12.8.0 and verified cache-backed installation and actual database operations.
- node-pty 1.1.0 left a Windows console-helper cleanup diagnostic. The official development-only 1.2.0-beta.18 passes the PTY harness without that diagnostic; it is explicitly pinned and remains subject to three-OS CI.
- Patched transitive Zod/minimatch versions are enforced through root overrides. The final npm advisory query reports zero known advisories; this is a point-in-time audit, not a universal security guarantee.
- The host volume exceeds the default 95% XERJ flood-stage watermark. Only the disposable synthetic probe uses an explicit startup limit of 99%. Production settings/defaults are unchanged, and this qualification is retained in the probe result.

# P02 — Multi-root workspaces and preserved local state

Status: **implemented and verified on Windows x64; cross-platform acceptance deferred**.
P00/P01 prerequisite gaps remain in [the ledger](../deferred-gaps.md); the user
authorized continuing development on 7 November 2026. No macOS/Linux execution is
claimed. Source identity and evidence hashes are in the local source/evidence manifests.

## Delivered behavior

`@kode/workspace` implements canonical root registration, access declarations,
Git discovery, verified content-addressed baselines and independent task trees.
The runner exposes authenticated workspace/folder/capture/tree RPCs; Commander
exposes their CLI commands and the rich terminal displays registered roots.
See [usage and boundaries](../workspace-and-commands.md) and [ADR-005](../metadata-persistence-decision.md).

## Verification

`node scripts/verify.mjs`: TypeScript, ESLint, the full integration suite, actual PTY
interaction, and JSON doctor all exit zero in the observed Windows user context.
`.artifacts/verification.json` records commands/statuses/durations; `.artifacts/vitest.json`
maps individual scenarios. The fixture manifests contain only synthetic source.
The shared CI matrix now includes these tests, but has not run remotely.

## Limits retained for later work

Ordinary folders use isolated snapshot mode; applying/integrating changes back into
sources is P11. File symlinks/submodules need explicit later support; they do not
silently bypass the boundary. Capture limits and exclusions are documented in usage.
OS/provider sandbox enforcement is a separate adapter obligation. Three-OS results
and native architecture qualification remain GAP-003/GAP-004.

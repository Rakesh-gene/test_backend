## Remaining qualification

Windows sandbox restrictions prevent `taskkill /T`; the real process tests therefore
run in the normal user context. OS refusal is surfaced as failed/unconfirmed teardown,
not hidden. Windows detached descendants outliving an exited parent need stronger
containment in P12. A hard runner crash blocks unfinished jobs and leaves an unready
environment; automatic safe orphan reconciliation remains P12. Full native-addon,
SDK/configuration combination coverage and remote three-OS CI are not claimed by a
passing local fixture. Report ingestion/proof closure is P09, and provider execution
and native approval relay remain P08/P10.
